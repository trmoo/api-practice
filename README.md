# API 실습실

주소를 부르면 JSON이 온다 — **데이터를 수집하는 방법**을 브라우저에서 직접 해 보는 수업용 웹앱.

고등학교 「정보」 `[12정02-03]` · 「데이터 과학」 `[12데과02-01]` 의 핵심 동사인
**「수집」**을 겨냥합니다. 학생이 **자기 학교 급식을 직접 가져와** 보는 것이 이 앱의 고비이자 재미입니다.

---

## 3줄 사용법

1. `dist/index.html` 을 더블클릭하면 바로 열립니다. (설치·서버 필요 없음)
2. 왼쪽부터 차례로 — **① 요청과 응답** 네 화면을 지난 뒤 **② 급식 API 실습** 네 화면을 합니다.
3. 인터넷이 안 되면 오른쪽 위 **[📦 연습 모드]** 를 누르세요. 미리 받아 둔 진짜 응답으로 똑같이 돌아갑니다.

---

## 화면 여덟 개 (1차시)

### ① 요청과 응답

| 화면 | 하는 일 |
|---|---|
| **1. 첫 요청** | 단추 하나로 강아지 사진 · 날씨 · 위키백과를 가져온다. 상태 코드와 걸린 시간을 보여 준다 |
| **2. 주소 해부기** | 주소를 고치면 프로토콜·호스트·경로·파라미터가 색으로 갈린다. 한글이 `%EC%99%80` 가 되는 과정을 한 글자씩 |
| **3. 파라미터 실험실** | 도시·항목·시간대를 고르면 주소가 실시간으로 다시 만들어지고, 보내면 답이 달라진다 |
| **4. JSON 탐험기** | 받은 JSON 을 나무로 펼치고, **값을 누르면 그 값을 꺼내는 경로**가 자바스크립트·파이썬 두 문법으로 적힌다 |

### ② 급식 API 실습

| 화면 | 하는 일 |
|---|---|
| **5. 학교 찾기** | 학교 이름으로 검색해 **시도교육청 코드 + 학교 코드**를 얻는다 |
| **6. 급식 조회** | 얻은 코드로 진짜 급식을 가져온다. 날짜를 바꿔 가며 실험한다 |
| **7. 경로 찾기** | 나무에서 값을 직접 눌러 다섯 문제를 푼다 (채점) |
| **8. 전처리·마무리** | `<br/>` 를 자르고 `(5.6.9)` 를 알레르기 이름으로 풀어 본다 + 점수판 |

문제는 모두 **15가지** — 주소 읽기 3 · 코드 빈칸 채우기 4 · 경로 찾기 5 · 전처리 3.

## 이 앱이 가르치는 것

* **주소가 곧 요청이다.** 파라미터를 바꾸면 다른 것을 물어보게 된다.
* **한글은 인코딩해서 넣는다.** `와우` → `%EC%99%80%EC%9A%B0`
* **응답은 JSON 으로 온다.** 중괄호는 이름표가 붙은 묶음, 대괄호는 0부터 세는 목록.
* **값에는 경로가 있다.** `데이터.mealServiceDietInfo[1].row[0].DDISH_NM`
* **★ HTTP 200 이라고 자료가 있는 건 아니다.** 나이스는 자료가 없어도 200 을 주고
  본문에 `INFO-200` 을 담아 보낸다. 상태 코드만 보고 넘어가면 안 된다.
* **★ 무료로 열려 있어도 공짜로 무한하지는 않다.** 인증키 없이는 언제나 5건까지다.
* **가져온 것으로 끝이 아니다.** 자르고 풀어야 쓸 수 있다 — 전처리.

## 두 가지 모드

이 앱은 다른 수업 앱과 달리 **진짜로 인터넷에 요청을 보냅니다.**
교실에서 인터넷이 끊기거나 학교 방화벽이 막으면 수업이 통째로 멈추므로, 모드를 둘 두었습니다.

| 모드 | 무엇을 하는가 |
|---|---|
| 🌐 **실제 호출** | 진짜 `fetch`. 상태 코드·걸린 시간이 그때그때 다르다 |
| 📦 **연습 모드** | 2026-08-30 에 미리 받아 둔 **진짜 응답**으로 똑같이 동작 |

* 요청이 실패하면 **앱이 스스로 연습 모드를 권합니다.**
* 연습 모드도 「5건 제한」·「자료 없으면 INFO-200」·「시간대를 빼면 GMT」를 **그대로 재현**합니다.
  그러지 않으면 학생이 실제와 다른 것을 배우게 되기 때문입니다.
* 두 모드가 다른 점(연습 모드에는 고등학교 140곳만 담겨 있음)은 화면에 밝혀 두었습니다.

**수업 전에 한 번 확인하세요.** 학교망에서 `open.neis.go.kr` 이 열리는지 미리 눌러 보시고,
막혀 있으면 처음부터 연습 모드로 진행하시면 됩니다.

## 개발자용

```bash
npm install        # 의존성 설치
npm start          # 개발 서버 (localhost:5177)
npm run build      # dist/index.html 한 파일로 빌드
npm test           # 시험 295가지
npm run check:syntax   # 소스 전수 문법·저작권·화면 수명 검사
npm run data       # 연습 모드용 응답을 다시 받아 온다
```

`npm test` 는 브라우저 없이 돌아가므로 **화면을 그리는 탭 파일을 부르지 않습니다.**
그래서 탭 파일의 문법 오류는 시험을 통과하고 빌드에서야 터집니다.
**빌드 전에 반드시 `npm run check:syntax` 를 함께 돌리세요.**

자세한 개발 기록과 주의할 점은 `CLAUDE.md` 에 있습니다.
